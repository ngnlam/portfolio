<Section id="problem" title="Two thousand chats, and every new one started from zero">

For three years I worked through problems with AI: growth analyses, requirement documents, course notes, code. The knowledge stayed inside about 2,000 separate chats in Claude and ChatGPT. A decision lived in one chat and its numbers in another, and every new conversation started from zero.

</Section>

<Section id="found" title="Chats are raw material, and an AI that writes notes will drift">

- **A chat is not a memory.** It holds the thinking, but not in a form I or an AI can look up, link or check.
- **AI-written notes drift without rules.** Left alone, an assistant creates duplicate notes, leaves notes unlinked and states facts without a source.
- **Methods travel, company facts don't.** The way I diagnose a funnel works at any company; the numbers belong to one project.

</Section>

<Section id="decisions" title="Rules first, then agents that follow them">

<Decisions>
<Decision title="Three layers: sources, wiki, rules">

Raw sources are never edited. Agents write a wiki on top of them, and a rules file says how. Any note can be traced back to the chat or document it came from.

</Decision>
<Decision title="Every claim cites its source">

Notes carry their sources; a fact the AI inferred is marked as inferred; when two sources disagree, the note keeps both with a warning. Phone numbers, keys and customer data stay out.

</Decision>
<Decision title="An agent enforces how notes link">

I wrote an 11-point link contract: every note needs topics, at least three meaningful links and at least one note pointing to it, and every concept says where I applied it. A script measures the graph; a link-keeper agent fixes what fails.

</Decision>
<Decision title="Parallel agents, separate files">

When ingesting thousands of chats, each agent owns one project's files and writes nothing else, and the link agent runs last, so no two agents ever write the same file.

</Decision>
<Decision title="Local and private">

The vault lives on my machine under git. I turned down sync extensions that could read work data.

</Decision>
</Decisions>

<Section id="shipped" title="Converters, an agent, two nightly jobs and a skill library">

- **Converters** for Claude and ChatGPT exports, Claude Code sessions and claude.ai projects, plus scripts that build the index, lint the vault and measure the link graph: 13 scripts in all.
- **A link-keeper agent and five vault skills** for ingesting sources, saving a work session, syncing chats, linting and weaving links.
- **Two scheduled jobs:** every night at 9:35 pm the system saves the day's chats and reads anything I drop in the inbox; every Sunday evening it syncs skills, re-links and cleans up. Each run ends with a git commit and a short report.
- **A library of 75 skills I created or curated**, from growth diagnosis to requirement writing, reused across projects.

<Section id="results" title="A memory I can query, and the one I used to rebuild this site">

- **Coverage:** every note has topics and none has fewer than three links; two in three links cross from one topic to another, which is where ideas connect.
- **In use:** independent agents checked every number on this site against the vault and its sources, and caught more than a dozen overstated claims before they went live. When I rewrote the car case, the vault showed that one growth figure came mostly from a traffic mix shift, so I removed it.
- **Next:** measure how much faster I find and reuse past work.

</Section>

<Section id="learned" title="Unlinked notes drift, so linking is enforced">

- Adding notes without linking them made the vault drift, so every change now goes through the link agent.
- Splitting ingestion by project, one agent per set of files, let many agents run at once without overwriting each other.

</Section>
